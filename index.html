1. 概覽／遊戲簡介

《數碼暴龍世界》（日：デジモンワールド／英：Digimon World）是 1999 年於 PlayStation 推出的養成＋RPG。 你扮演墜入數碼世界的少年，在 File Island 與夥伴 Digimon 一起把荒廢的 File City 重建起來。

核心循環

餵食／清理 → 訓練屬性 → 野外戰鬥 → 進化／招募夥伴 → 解鎖城市設施與新地圖。

起點夥伴

通常由 Botamon → Koromon → Agumon 開始；之後依照顧、數值與戰績走上不同進化樹。

遊戲目標

擴大 File City 人口（招募 Digimon）、探索島嶼、挑戰高難度區域如 Mt. Infinity，並理解「壽命」機制。

重點：這作不是傳統回合制隊伍 RPG，而是「一隻主 Digimon 陪你長大」。 壽命（Lifespan）會消耗；Digimon 死亡後可再養成，城市進度通常保留。

2. 養成基礎

養成狀態欄要經常看。忽略任何一項都可能變成 Care Mistake（照顧失誤），直接影響進化與壽命。

主要狀態

狀態英文說明與建議
飢餓 Hunger 肚餓會喊；不及時餵會扣快樂並記 Care Mistake。別一次餵到過飽（Weight 暴升）。
便便 Poop / Waste 便便要盡快清；放著會生病、扣快樂、累積 Care Mistake。
快樂 Happiness 讚美、正確餵食、勝利戰鬥可升；忽略需求、輸戰、過多責罵會跌。
紀律 Discipline 責罵不當行為、規律訓練可升；過度放縱或亂罵會亂。高 Discipline 常連到「天使系／正經系」進化。
體重 Weight 吃肉、休息會升；訓練、跑步、特定食物可降。進化常有目標 Weight 區間。
壽命 Lifespan / Life 隨時間／活動消耗。Care Mistake、生病、過勞會加速折壽；休息與良好照顧可緩和。
照顧失誤 Care Mistakes 錯過餵食、清便、治療等會累積。少失誤 → 較「正面」進化；多失誤 → 較「黑暗／歪系」路線較易出現。

日常照顧節奏

  1. 聽到喊叫（Hungry／Poop／Sick）→ 立刻處理，唔好拖。
  2. 餵食優先用適合當前目標體重的食物（想減重就少肉、多菜／訓練）。
  3. 訓練前後留意疲勞；累透就休息，避免硬撐出事。
  4. 適度 Praise（讚美）與 Scold（責罵）：亂罵會扣 Happiness。
  5. 生病先治；帶病訓練／探險風險高。
常見誤解：「永遠不罵」不一定最好。某些進化需要一定 Discipline；關鍵是「該罵才罵」，並即時回應需求以減少 Care Mistakes。

3. 訓練與能力值

File City 的 Gym／訓練設施（隨城市發展解鎖）用來拉六圍。 訓練有成功率，失敗浪費時間但仍可能影響疲勞與體重。

六圍簡表

能力英文用途
體力HP耐打；高難度區與長線戰鬥必備。
魔力／技力MP施放 Technique（必殺／特殊技）消耗。
攻擊Offense (Off)普攻與多數攻擊技傷害。
防禦Defense (Def)減傷；坦克型進化常看重。
速度Speed影響先手與迴避相關表現。
智力Brains技學習／命中相關；多條「賢者／天使」路線重視。

訓練方式與建議

HP／Defense 向

偏重防禦與體力訓練，適合走坦克（如部分 Tyrannomon／Shellmon 路線思維）。配合較高 Weight 目標時常見。

Offense 向

主攻輸出。Agumon → Greymon 系通常要足夠攻擊；但別忽略 Def／HP，否則野外被反殺。

Speed 向

想走敏捷系或某些鳥／獸路線時加強。亦可輔助脫戰與先手。

Brains／MP 向

想學較多 Technique、走 Angemon 等路線時重要。MP 不足會變成「只會普攻」。

實務建議

  • 每次進化前先定「目標形態」，再決定主攻哪 2–3 項數值，避免平均廢功。
  • 訓練會耗壽命與體力；進化窗口接近時，改以「補門檻」為主，勿無腦刷到老死。
  • 用道具（如訓練輔助類）可提高效率，但早期資源有限，留給關鍵衝刺。
  • Weight 與訓練互相拉扯：狂練通常偏瘦；狂吃會肥——配合進化條件微調。

4. 戰鬥要點

野外遇敵後進入戰鬥畫面。你的 Digimon 會自動行動，但你可以設定策略傾向、選擇 Technique，並留意 MP 與狀態。

技巧／MP

  • Technique：各 Digimon 可學多種技能；強技耗 MP 高。
  • MP 見底時只能普通攻擊，輸出與控場大幅下降——出遠門前確認 MP／回復道具。
  • 戰鬥勝利可提升經驗與部分養成相關數值；連勝有助部分進化條件（「戰鬥數／勝利數」類）。

狀態與風險

  • 中毒、麻痺、混亂等狀態要優先處理；帶病硬闖高危區容易暴斃。
  • 對手屬性／技能克制存在手感差：打不過就撤退回城補滿再來。
  • Boss／守護型敵人（如通往 Mt. Infinity 沿途）建議先把六圍與技能練熟。
這作戰鬥節奏偏「養成成果的驗收」。輸多了未必只是操作問題——可能是進化體不適合該區，或 HP／Def 門檻不夠。

5. 進化概論與常見路線

社群整理、非官方保證。 進化由多項條件組合觸發（數值門檻、Weight、Care Mistakes、戰鬥數、快樂／紀律、累計照顧時間等）。 不同版本／修補／模擬器時序可能有出入；以下為社群長年整理的「常見方向」，唔係 Bandai 官方保證公式。

進化邏輯（簡化）

  • 時間到了且條件吻合 → 進化；條件衝突時，遊戲會按優先規則選一條。
  • Care Mistakes 少、Discipline／Happiness 高 → 較易偏「光／秩序」向。
  • Care Mistakes 多、Discipline 低 → 較易偏「暗／歪」向。
  • 特定 Weight 區間常是分水嶺（過重／過輕都會鎖死某些形態）。
  • Offense／Defense／Speed／Brains／HP／MP 各有門檻；「剛好達標」比「單一屬性爆表」更重要。

Agumon 起點：常見 Child → Adult 方向

目標大致傾向（社群整理）備註
Greymon 均衡偏攻防、Care Mistakes 少、中等 Weight、一定戰鬥歷練 最經典「王道」成體；之後可衝 MetalGreymon 等。
Tyrannomon 較高 Weight／HP／Offense 取向，條件與 Greymon 相近但更「厚重」 坦克臉；適合作前期扛傷夥伴路線之一。
Meramon 偏 Offense／Speed、Weight 管理、火焰系技學習方向 輸出臉；注意生存能力。
Birdramon Speed／MP 等飛行系傾向，Weight 不宜過重 機動向；探索期手感輕快。
Centarumon Brains 較高、紀律良好 常與「智系／槍系」印象綁在一起。
Monochromon Defense／HP、較重 Weight 防禦臉；練裝甲思路。
Devimon Care Mistakes 偏多、Discipline 偏低、黑暗向數值 「歪養」代表；唔等於強，但劇情／收集向受歡迎。
Angemon Care Mistakes 少、Discipline／Happiness 高、Brains 足夠 「好孩子」路線；之後可往更高階光系想像。

Greymon → MetalGreymon（常見延續）

社群路線多要求 Greymon 期間把 Offense／Defense／Speed／Brains 等多項拉到高門檻， 並維持較少 Care Mistakes、合適 Weight 與足夠戰鬥數。失敗時可能落入其他完美體／突變，或錯失窗口。

想收集圖鑑：刻意走 Devimon／Numemon 等「失敗／歪系」也是玩法之一。 Numemon 常與大量 Care Mistakes、低數值或特定惡搞條件連結——可作彩蛋養成。

6. 主要地點

File Island 以 File City 為中心向各生態區擴散。城市設施愈多，訓練、商店與劇情推進愈順。

File City

主城與樞紐。招募 Digimon 進駐可開商店、Gym、餐廳、診所等。每次出門前在此補狀態。

Native Forest

初期森林區。教學向遭遇戰、基礎道具與劇情 NPC。適合暖機與練手。

Tropical Jungle

高濕叢林，敵人與陷阱感較強。帶足回復，留意迷路；適合中前期探索。

Great Canyon

峽谷地形，移動路徑較繞。注意掉落／捷徑與中階對手，適合有穩定成體後挑戰。

Gear Savannah

草原／機械遺跡氛圍並存的開闊區。遭遇戰頻率感高，練級與收集素材常用。

Factorial Town

工廠城鎮風格地圖，機關與機械系 Digimon 多。解謎／繞路前先存好進度習慣。

Freezeland

冰雪地帶，耗損與敵人壓力較大。出門前確認 HP／抗性向準備，避免硬闖。

Misty Trees

霧林，視野與方向感易亂。跟著地標、逐步開圖；適合中後期。

Ancient Dino Region

古代恐龍風格區域，對手偏肉。建議高 Def／HP 或成熟輸出技再進入。

Mt. Infinity

後期高山／試煉向地圖，層層挑戰。務必以成熟完美體思維準備，並預留壽命。

Back Dimension

特殊／後期向空間，風險與獎勵都高。當成終盤內容，勿過早送死。

探險建議：壽命有限——每次遠征定一個目標（招募某 Digimon、拿某道具、打通某捷徑），達標即回城，避免「順便再看看」看到老死在野外。

7. 道具與食物

常見食物（影響 Hunger／Weight／心情）

類型例子（常見稱呼）用途
肉類 Meat、大份肉食等 快速消飢、易升 Weight；衝重型進化前常用，減重期少吃。
蔬果／清淡 蔬菜、水果類 補飢較溫和，Weight 負擔較低；管理體重時優先。
特殊餐 城市餐廳／活動料理 可能附帶 Happiness 或其他加成；視當前養成目標選用。

恢復與狀態

  • HP 回復：各級 Recovery／藥水類——出門基本盤。
  • MP 回復：長線戰鬥或技攻隊必帶。
  • 狀態治療：解毒、醒神等；對應叢林／毒系區域尤重要。
  • 診所：回 File City 找醫療設施處理重病，比野外硬扛安全。

訓練／養成輔助

  • 提升某項訓練成功率或收益的道具：留給「進化前最後衝刺」。
  • 影響 Happiness／Discipline 的道具：微調進化傾向時好用，但唔好依賴到忽略日常照顧。
  • 便攜廁所／應急清理類（視你取得的道具）：減少野外 Care Mistake 風險。

商店庫存隨 File City 發展與招募對象變化——多找居民對話，常有新貨與隱藏提示。

8. 實用 Tips／常見坑

  1. 先顧命再追稀有。壽命見底仲喺 Mt. Infinity 迷路＝進度倒退感最重。
  2. Care Mistake 會說話。想 Angemon 就唔好當佢隱形；想 Devimon 就有意識地「放縱」——但要可控。
  3. 唔好只堆 Offense。玻璃大炮喺自動戰鬥裡好易暴斃。
  4. Weight 要用食物＋訓練對沖。眼見數字，唔好估。
  5. 城市建設＝系統解鎖。卡關時先問：係咪仲未招募到開設施／開門的 Digimon？
  6. 存檔習慣。進化前、進新地圖前、挑戰強敵前各存一次（視平台／記憶卡策略）。
  7. 死亡唔等於遊戲結束。重新養成時可帶著城市進度再衝圖鑑與路線。
  8. 別把後作規則套入。Re:Digitize／Next Order 的農場、多人、進化石邏輯與此作不同。
